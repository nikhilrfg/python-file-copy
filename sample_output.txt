# Python File Copy Program - Sample Output

## Test 1: Copy an Existing File

Command:
python file_copy.py

Enter the source file name: sample.txt
Enter the destination file name: sample_copy.txt
45 byte(s) successfully written

Expected Result:
The program creates sample_copy.txt containing the same data as sample.txt.

Verification:
(Get-FileHash sample.txt).Hash -eq (Get-FileHash sample_copy.txt).Hash

True
